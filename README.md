# Порядок выполнения скриптов

Выполнять скрипты в порядке, который обозначен
---

- BuildFolderDatabase.py
(парсит файлы из директории books_dir и составляет оглавления по чанкам, страницам, текста);
- VectorStoreAndQuery.py
(создает векторную базу данных, впоследствии загружает ее, так же выполняет поиск по ней);
- AssistantFinalResponse.py
(основной ассистент, принимает запросы пользователя, а так же получает результат от базы и обрабатывает ее)
